# Prototype

Het eerste ontwerp van Kleurhoek, gemaakt als losse HTML-pagina. Het is de referentie voor fase 1: de 65 platen, kleur-op-nummer, leerbladen, boekjes, koelkast, filters op onderwerp, wereld, feestdag en leeftijd.

- `kleurhoek-artifact.html`: de versie die als gedeelde pagina draait (PDF via downloads).
- `kleurhoek-standalone.html`: de losse versie met het printvenster van de browser.

De platen (tekenfuncties, kleur-op-nummer-codes, woorden en telvragen) worden in fase 1 overgezet naar de catalogus. Deze map wordt daarna niet meer aangepast.
