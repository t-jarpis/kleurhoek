# Kleurhoek admin panel

```sh
API_URL=http://localhost:3001 ADMIN_DEV_TOKEN=<zelfde als API> pnpm --filter @kleurhoek/admin dev   # http://localhost:3002
```

Start de API met `NODE_ENV=development ADMIN_DEV_TOKEN=<token>`. Tot Zitadel gekoppeld is, draait het admin panel alleen lokaal. Pagina's: dashboard (analytics), rate limits (bekijken en wijzigen).
